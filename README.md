# tajadod-media

Public images for the Tajadod (@tajadod.co) 30-day Instagram plan, scheduled through Metricool.

- `day-01/` … `day-30/`: carousel slides (1080×1350), posted in order 01, 02, 03…
- `stories/story-01.jpg` … `story-30.jpg`: daily Stories (1080×1920)

Source and captions live in the private `tajadod-ai` repo under `marketing/`.
